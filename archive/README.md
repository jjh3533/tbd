# archive

이미 실행이 끝난 1회성 스크립트/데이터/로그 보관용 폴더입니다. 코드에서 더 이상
import/참조되지 않으며, 삭제하지 않고 남겨둔 이유는 "당시 무엇을 왜 했는지"를
나중에 다시 확인할 수 있게 하기 위함입니다 (자세한 작업 배경은 `../HISTORY.md` 참고).

- `scripts/` — 루트에 있던 1회성 조사/디버그/검증/수정 스크립트
- `product_pages_scripts/` — `product_pages/scripts/`에 있던 카테고리별 1회성 배치 생성/이미지 처리 스크립트
- `data/` — 더 이상 코드에서 읽지 않는 데이터 (옛 URL 목록, 스키마가 바뀌기 전 CSV 등)
- `logs/` — 과거 실행 결과 로그/스크래치 산출물

비슷한 작업을 다시 해야 한다면 여기서 참고용으로 꺼내 쓰되, 활성 파이프라인에는
다시 끌어오지 마세요 (그러면 다시 루트가 복잡해집니다).
